Keyboard Shortcuts

Desktop shortcuts for docs navigation and playback.

Docs shortcuts

ShortcutAction
/Focus docs search.
EscClose search and clear focus.

Playback shortcuts

ShortcutAction
SpacePlay or pause.
Left ArrowSeek back by the configured skip amount.
Right ArrowSeek forward by the configured skip amount.
Up/DownAdjust volume when supported.
FToggle fullscreen.

Notes

Keyboard behavior can differ if focus is inside a text input, menu, browser view, or external player. External players use their own shortcut map.
