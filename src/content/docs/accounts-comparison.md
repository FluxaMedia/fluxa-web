## Quick comparison

| Account | Required? | Use it for |
| --- | --- | --- |
| No account | No | Local profiles, local addons, local playback, local library. |
| Nuvio | No | Cross-device Fluxa sync for profiles, library, progress, addons, and collections. |
| Stremio | No | Using a Stremio account from the web account page when supported. |
| Trakt | No | Movies and TV watch history, lists, scrobbling. |
| MyAnimeList | No | Anime lists and episode progress. |
| Simkl | No | Movies, TV, and anime in one tracking account. |

## Recommended setups

- **Single device:** no account is required. Add tracking only if you want external history.
- **Desktop plus Android:** use Nuvio if you want Fluxa state to follow you.
- **Anime-heavy use:** connect MyAnimeList or Simkl.
- **TV and movie tracking:** connect Trakt or Simkl.

## Profile scope

Accounts are profile-scoped. One profile can connect a Trakt account while another profile uses a different account or no account at all. Switching profiles changes addons, library, settings, and connected services.
