## Addon terimleri

| Terim | Anlamı |
| --- | --- |
| Addon | Katalog, üstveri, akış veya altyazı sağlayan uzak servis. |
| Manifest | Bir addon'u ve yeteneklerini tanımlayan JSON belgesi. |
| Katalog | Başlıkların listelendiği satır veya gezilebilir liste. |
| Üstveri | Poster, özet, oyuncular, fragmanlar, bölümler ve görseller gibi ayrıntılar. |
| Akış | Oynat'a bastıktan sonra dönen, oynatılabilir kaynak sonucu. |

## Kaynak terimleri

| Terim | Anlamı |
| --- | --- |
| Debrid | Desteklenen bağlantıları veya torrentleri hızlı doğrudan akışa çeviren sağlayıcı. |
| Usenet | Hızlı medya kaynağı sunabilen sağlayıcı/indeksleyici ekosistemi. |
| Önbellekli | Sağlayıcının dosyayı akışa hazır tuttuğu durum. |
| Remux | Ek sıkıştırma içermeyen veya çok az içeren yüksek kaliteli kaynak. |
| WEB-DL | Doğrudan bir yayın servisinden alınmış video. |

## Uygulama terimleri

| Terim | Anlamı |
| --- | --- |
| Profil | Kendi kütüphanesi, addon'ları, ayarları ve hesapları olan ayrı kullanıcı alanı. |
| Kütüphane | Kaydedilen başlıklar, izlemeye devam, koleksiyonlar ve ilgili geçmiş. |
| Eşitleme | İsteğe bağlı, cihazlar arası veya üçüncü parti hesap güncelleme akışı. |
