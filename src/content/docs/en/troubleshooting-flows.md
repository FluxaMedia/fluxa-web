## Home is empty

1. Check Settings -> Addons: is at least one catalog addon installed and enabled?
2. Check Settings -> Home Catalogs: are rows hidden?
3. Open the manifest URL in a browser: does it load?
4. Try another catalog addon to separate app issues from addon downtime.

## No streams

1. Confirm you installed a stream addon, not only a catalog addon.
2. Try a popular title to rule out niche title coverage.
3. Check addon configuration for required API keys.
4. Try another stream addon.

## Video buffers or stops

1. Switch to a different source from the player.
2. Prefer direct/debrid sources over weak torrents when available.
3. Lower quality from 4K to 1080p.
4. Check network speed and VPN behavior.

## Sync missing data

1. Confirm the correct profile is active.
2. Check account connection status.
3. Wait for both devices to come online.
4. Sign out and back in if status looks stale.

## Login callback failed

1. Retry the sign-in flow once.
2. Make sure Fluxa is installed, not just unpacked temporarily.
3. On Linux, run the installed app once from your app launcher or terminal.
4. Reinstall if protocol links still do not return to Fluxa.
