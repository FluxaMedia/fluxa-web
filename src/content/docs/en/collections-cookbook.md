## Seasonal anime collection

1. Create a collection called Seasonal Anime.
2. Add folders for currently airing, popular, and completed anime catalogs.
3. Use poster layout for title browsing.
4. Connect MyAnimeList or Simkl if you want tracking.

## Kids profile collection

1. Create a separate profile.
2. Install only addons and catalogs appropriate for that profile.
3. Create collections by age range or genre.
4. Keep account connections separate from adult profiles.

## Top-rated movies row

1. Create a Movies collection.
2. Add a folder from a top-rated movie catalog.
3. Filter by genre if needed.
4. Pin it near the top of Home for quick access.

## Export and import examples

Use export when moving collections between devices or profiles. Review imported JSON before saving if you received it from someone else.
