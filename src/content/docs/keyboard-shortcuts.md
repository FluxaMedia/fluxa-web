## Docs shortcuts

| Shortcut | Action |
| --- | --- |
| `/` | Focus docs search. |
| `Esc` | Close search and clear focus. |

## Playback shortcuts

| Shortcut | Action |
| --- | --- |
| `Space` | Play or pause. |
| `Left Arrow` | Seek back by the configured skip amount. |
| `Right Arrow` | Seek forward by the configured skip amount. |
| `Up/Down` | Adjust volume when supported. |
| `F` | Toggle fullscreen. |

## Notes

Keyboard behavior can differ if focus is inside a text input, menu, browser view, or external player. External players use their own shortcut map.
