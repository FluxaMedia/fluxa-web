## Addon terms

| Term | Meaning |
| --- | --- |
| Addon | Remote service that provides catalogs, metadata, streams, or subtitles. |
| Manifest | JSON document that describes an addon and its capabilities. |
| Catalog | A row or browsable list of titles. |
| Metadata | Details like poster, synopsis, cast, trailers, episodes, and artwork. |
| Stream | A playable source result returned after pressing Play. |

## Source terms

| Term | Meaning |
| --- | --- |
| Debrid | Provider that converts supported links or torrents into fast direct streams. |
| Usenet | Provider/indexer ecosystem that can supply fast media sources. |
| Cached | Provider already has the file ready to stream. |
| Remux | High-quality source with little or no extra compression. |
| WEB-DL | Video sourced directly from a streaming service. |

## App terms

| Term | Meaning |
| --- | --- |
| Profile | Separate user space with its own library, addons, settings, and accounts. |
| Library | Saved titles, continue watching, collections, and related history. |
| Sync | Optional cross-device or third-party account update flow. |
