Contributing Docs

How to report docs issues and write useful docs changes.

Report docs issues

Open a GitHub issue with the page URL, the unclear or outdated section, and what you expected it to say. Screenshots are useful when the app UI changed.

Writing style

  • Prefer task-first headings.
  • Use short paragraphs and concrete steps.
  • Call out platform-specific behavior.
  • Avoid promising that third-party addons or providers will always work.
  • Link related docs instead of repeating long explanations.

Screenshots and examples

Use screenshots when a user needs to match text to UI. Use code blocks for manifest patterns, paths, config snippets, or mpv options. Keep examples generic unless a page is explicitly about a provider.
